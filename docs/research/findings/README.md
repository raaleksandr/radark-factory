# Research findings

Short English summaries of returned reports, `HR-NNN-<slug>.md`, written in the same session as the intake. Index: the [register](../README.md).

Each summary gives:

- links to the brief and the report, and the date summarised;
- what the report establishes, each finding with its confidence (*high* / *medium* / *low*) and the reason. A claim without a source is *low*; terms and limits count as *high* only with a primary source (Anthropic's terms, usage policy or docs; a project's own repository or docs);
- the sources and their dates;
- for each candidate tool: what it is (exact name, URL), how it controls Claude Code, Windows support, licence, maturity, cost, and a provisional score per requirement (met / partly / not met / unknown);
- what remains unknown, and for each gap a decision waits on: a follow-up question in the register or a spike.

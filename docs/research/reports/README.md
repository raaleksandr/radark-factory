# Research reports

Returned reports, stored **unedited** as `HR-NNN-<slug>.md`, so findings can be checked against them. Index: the [register](../README.md).

- Add only a header line at the top: `Received: YYYY-MM-DD · Tool: <name>`.
- Reports in Russian are stored as returned.
- One exception, noted at the top of the report with the date and what was changed: **redaction** of e-mail addresses, private persons' contact details or anything that looks like a credential.

Each report is summarised in [../findings/](../findings/README.md) in the same session.
